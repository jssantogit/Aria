# AMS genre corpus v2 — user-directed revision

Retain Pop, Rock, Electronic, Jazz, K-pop, Metal, R&B and Hard Rock.
Replace Folk, House, Techno, Trance, Smooth Jazz and Bluegrass with
Soul, Samba, Blues, Pagode, Trap and Indie. Rap replaces the overlapping
Hip-hop case (Apple uses Hip-hop/rap). All 15 v2 landing cases require 6
distinct albums. Original IDM frozen matrix remains intact.

Public source references (BR):
- Soul e funk: https://music.apple.com/br/curator/apple-music-soul-e-funk/976439585
- Pagode e samba: https://music.apple.com/br/curator/apple-music-pagode-e-samba/982356287
- Blues: https://music.apple.com/br/curator/apple-music-blues/976439528
- Indie: https://music.apple.com/br/curator/apple-music-indie/976439541
- Rap: https://music.apple.com/br/curator/apple-music-hip-hop-rap/989061413

No independent Trap curator established. The Hip-hop/rap curator may
nominate Trap albums only with explicit Trap genre labels. For shared
Soul/Funk and Samba/Pagode curators, exact album genre metadata is required
to count content separately; a shared page never counts as two dedicated
curators. Preserve source provenance and report label-verified shared
curation distinctly. This revision is not a UI taxonomy change and is not
comparable as a repeated run of the original IDM frozen corpus.
