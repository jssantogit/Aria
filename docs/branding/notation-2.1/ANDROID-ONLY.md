# Android-only product scope

Desktop, TV and Wear app source trees have been removed from the current branch (Git history remains available). Android Gradle uses app, shared, sharedUi. The JVM test hosts of shared modules are deliberately retained. Phone-side wearable transport and installer are inert temporary compatibility surfaces; Wearable Play services, remote interaction and ADB installer dependencies are removed. Remaining watch call sites and hidden settings types should be deleted in a focused cleanup after verifying Android behavior. Android Auto, Cast and normal Bluetooth/media routing are unaffected product features. The retired-backend audit is scoped to active Android and shared sources. No historical upstream attribution or license notice is altered in retained code.
